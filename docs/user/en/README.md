# Nextcloud Collectives Sync – user manual

This manual describes how the plugin works and what each setting does. Installation, requirements and the risks are on the [main page](../../../README.md).

| Page | What you find there |
|---|---|
| [Getting started](getting-started.md) | Sign-in (browser or app password), the first sync, what your vault looks like afterwards. |
| [When the plugin syncs](sync.md) | Startup, interval, after changes, back in the foreground, manual sync; quiet automatic runs; the status bar; what is not synced. |
| [Structure](structure.md) | New, renamed, moved and deleted pages and collectives, in both directions; the confirmation dialog; the mass-deletion guard. |
| [Conflicts](conflicts.md) | When a conflict happens, conflict copies, the conflict dialog, the setting "Conflicts", editing in the browser at the same time. |
| [Emoji, tags, links and attachments](tags-emoji-links-attachments.md) | Page emoji and tags in the properties, links between pages, images and other files. |
| [Settings](settings.md) | Every setting in the order of the settings tab: effect, default, values, risks. |
| [Commands and menus](commands.md) | Commands, ribbon icon, context menu entries, status bar. |
| [Troubleshooting](troubleshooting.md) | The log, error messages and what to do, frequently asked questions. |

The manual uses the English texts of the plugin. If Obsidian runs in German, the plugin shows German texts; the [German manual](../de/README.md) uses those.
