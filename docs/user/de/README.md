# Nextcloud Collectives Sync – Handbuch

Dieses Handbuch beschreibt, wie das Plugin arbeitet und was jede Einstellung bewirkt. Installation, Voraussetzungen und Risiken stehen auf der [Hauptseite](../../../README.de.md).

| Seite | Was du dort findest |
|---|---|

| [Wann synchronisiert wird](sync.md) | Start, Intervall, nach Änderungen, zurück im Vordergrund, von Hand; stille automatische Läufe; die Statusleiste; was nicht synchronisiert wird. |
| [Struktur](structure.md) | Neue, umbenannte, verschobene und gelöschte Seiten und Collectives in beide Richtungen; der Bestätigungsdialog; der Schutz vor Massenlöschung. |
| [Konflikte](conflicts.md) | Wann ein Konflikt entsteht, Konfliktkopien, der Konflikt-Dialog, die Einstellung „Konflikte“, gleichzeitiges Bearbeiten im Browser. |
| [Emoji, Tags, Links und Anhänge](tags-emoji-links-attachments.md) | Emoji und Tags einer Seite in den Eigenschaften, Links zwischen Seiten, Bilder und andere Dateien. |
| [Einstellungen](settings.md) | Jede Einstellung in der Reihenfolge der Einstellungen: Wirkung, Standardwert, Werte, Risiken. |
| [Befehle und Menüs](commands.md) | Befehle, Symbol in der Seitenleiste, Kontextmenüs, Statusleiste. |
| [Hilfe bei Problemen](troubleshooting.md) | Das Protokoll, Fehlermeldungen und was zu tun ist, häufige Fragen. |
